# 🎂 Romantic Birthday Celebration Web Experience ❤️

An immersive, romantic, interactive birthday website featuring:
- **Screen 0:** Romantic Heart Gateway (Pulsing 3D Heart with Heartbeat Sound)
- **Screen 1:** Passcode Lock Screen (PIN: 123456)
- **Screen 2:** 3D Interactive Envelope with Romantic Letter (Typewriter Animation)
- **Screen 3:** Hanging Clothesline Memory Gallery with Wooden Pegs
- **Screen 4:** Interactive Vinyl Record & Spotify Player with Live Karaoke Synced Lyrics (*Eppadi Vandhaayo - Aaromaley*)
- **Screen 5:** Retro Cassette Player with Sliding Ticket & 35mm Memory Filmstrip (Opens on CLICK HERE)
- **Screen 6:** Floating Polaroid Drifting Memories Climax & Ambient Twinkling Stars
